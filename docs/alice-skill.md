# Навык «Моя затея» для Алисы — runbook

> Статус: локальный backend для Алисы реализован частично. Общий текстовый
> процессор, durable webhook queue, авторизация, базовый диалог и продолжение
> длинного ответа покрыты тестами; весь voice gateway suite проходит.
> Это не подтверждает облачный запуск, публикацию навыка, HTTPS-доступность
> или работу на колонке. Alice отключена по умолчанию (`ALICE_ENABLED=false`).
> Внешние шаги (черновик навыка, Яндекс ID, HTTPS-маршрут, модерация,
> проверка на колонке) — вручную владельцем; до их выполнения
> `ALICE_ENABLED` остаётся `false`.

## Что реализовано в backend

- Общий обработчик текста `text_turns.py`: один сервис за STT диктофона
  и за Алисой. Модель, промпты, Git outbox и история не менялись.
- Устойчивая очередь `data/archive/alice.sqlite3`: события, черновики,
  задания; идемпотентность по ключу `(skill_id, session_id, message_id)`;
  повтор возвращает прежний ответ; при запуске `running`-задания
  возвращаются в очередь с прежними ID.
- Быстрый webhook `POST /api/alice/webhook`: бюджет 2 с, тело ≤ 64 KiB,
  30 запросов/мин на владельца; LLM/Git в обработчике не вызываются.
- Авторизация через Яндекс ID (`login.yandex.ru/info`, timeout 1 с,
  positive-cache 60 с); недоступность API — отказ без доступа к vault.
- При отсутствии токена отправляется верхнеуровневый
  `start_account_linking` только на поддерживающей его поверхности;
  `account_linking_complete_event` проверяет токен и не создаёт пустую заметку.
- Диалог: команды распознаются только как целые реплики; «Запиши
  дословно: …» для буквального текста; черновик ≤ 12 000 символов без
  молчаливой обрезки; «Готово?» отдаёт сохранённый результат, «Сохранила»
  звучит только из подтверждённого writer'ом ответа. Длинные ответы можно
  продолжать командой «Дальше»; номер части сохраняется с защитой от повторов.
- Recorder и Alice используют один экземпляр `TextTurnProcessor`, поэтому
  сериализация по общему контексту действует для обоих входов.

## Внешние шаги (задача 1 плана, вручную)

1. Проверить домен и reverse proxy с доверенным сертификатом; наружу
   публикуется только `POST /api/alice/webhook` — `/api/voice/*`, `/docs`,
   `/metrics`, `/data/*` остаются закрытыми.
2. Создать приватный черновик навыка «Моя затея» в консоли
   [Яндекс Диалогов](https://dialogs.yandex.ru); проверить активационное имя.
3. Зарегистрировать приложение в
   [Яндекс ID](https://oauth.yandex.ru), настроить связку аккаунтов по
   официальной инструкции и пройти её из приложения; проверить передачу
   токена на колонке.
4. Снять fixtures реальных запросов (старт, SimpleUtterance,
   ButtonPressed, новая сессия, ping, событие linking) и сверить
   обработку пауз/длинных реплик на реальной поверхности.

Без доступа к аккаунту владельца и публичному домену эти шаги остаются
непроверенными; локальные тесты не заменяют их.

## Включение на сервере

```bash
# .env рядом с docker-compose.yml:
ALICE_ENABLED=true
ALICE_SKILL_ID=<id из консоли Диалогов>
ALICE_ALLOWED_YANDEX_ID=<id из GET login.yandex.ru/info>
ALICE_CONTEXT_DEVICE_ID=<существующий device_id диктофона>
```

Затем `docker compose up -d backend`. Отключение — `ALICE_ENABLED=false`
(маршрут и worker не создаются).

## Проверка перед основным vault (задача 6 плана)

- Отдельный временный vault с bare origin: Alice capture → recorder amend;
  recorder capture → Alice query/plan; параллельные обращения; конфликт;
  дубль webhook; рестарт worker.
- `python -m pytest -q backend/src/voice_gateway` — зелёный.
- `docker compose config --quiet` — валидно.
- Сборка backend-образа прошла локально. Полный интеграционный прогон через
  временный vault с bare origin ещё не выполнялся.
- В journald нет токенов, реплик и содержимого заметок.

## Известные ограничения

- Сопоставление аккаунта с контекстом не проверяет, кто говорит возле
  колонки: привязанный аккаунт разрешает доступ всем в помещении.
- Длинная диктовка собирается из нескольких реплик; непрерывной
  десятиминутной записи через протокол Алисы нет.
- До модерации приватного навыка доступ владельца невозможен; для
  первого прогона используется ответ-заглушка без vault.
