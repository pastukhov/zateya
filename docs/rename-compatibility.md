# Переименование в «Затею»

Имя устройства на экране, в настройке, сети точки доступа и mDNS теперь «Затея» (`Zateya-Setup-XX`, `zateya-<MAC>.local`). После прошивки старые адреса mDNS и имя точки доступа больше не работают.

Существующие пользовательские данные сохраняются на прежних местах. Пространство NVS `hermes` на устройстве содержит Wi-Fi, VPN, адрес сервера и яркость; его переименование сбросило бы настройки. В хранилище Obsidian остаются папка `Hermes/` и ссылки на неё, чтобы заметки и связи не исчезли. Путь базы Codex Agent, файл окружения, тома Docker и имя действующего проекта Compose тоже остаются прежними при переносе работающей установки. Эти имена обозначают формат и место уже записанных данных, а не имя продукта.

В коде по-прежнему есть необязательный старый провайдер `hermes` и его переменные `HERMES_*`. Текущая установка использует `VOICE_AGENT_PROVIDER=codex`. При чистом развёртывании можно выбрать новые пути хранения отдельно; существующие данные автоматически не переносятся.
