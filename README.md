# Затея · Zateya

Затея — карманный голосовой помощник на M5Stack StickS3. Он превращает поток мыслей в заметки Obsidian и связанную LLM Wiki, помогает развивать идеи и сохраняет планы и задания по принципу «Ramble your idea, then build».

Документация: [Русский](docs/ru/index.md) · [English](docs/en/index.md).

В проект входят прошивка и один серверный Voice Gateway. Gateway выполняет распознавание речи, обращается к настроенному OpenAI-совместимому Chat Completions endpoint, проверяет и записывает Markdown в Obsidian, синтезирует ответ и в фоне публикует изменения через Git. Codex CLI и аккаунт Codex не требуются. Все постоянные каталоги лежат рядом с Compose в `data/`.

## Быстрый запуск

```sh
cp .env.example .env
# Укажите LLM_*, STT_*, TTS_* и токены устройств в локальном .env.
chmod 600 .env
```

Для развертывания на сервере подготовьте существующий Obsidian vault в `data/obsidian`, настройте Git SSH в `data/ssh` и следуйте [инструкции для Linux-сервера](deploy/server-migration.ru.md). Для проверки конфигурации и тестов смотрите [руководство разработки](docs/development.md).

Compose использует host networking; ограничьте доступ к порту Gateway доверенной LAN/WireGuard. Значения `LLM_API_KEY`, STT/TTS-ключи и токены устройства передаются только процессу gateway и не выдаются веб-интерфейсу диктофона.

## Подключение StickS3

Без сохранённых Wi-Fi настроек устройство поднимает открытую сеть `Zateya-Setup-XX`, где `XX` — последние два hex-символа Wi-Fi MAC. Телефон обычно предлагает открыть setup portal; если нет, перейдите на `http://192.168.4.1/`.

В веб-форме выберите Wi-Fi и укажите адрес Gateway и device token. Полный setup доступен и после подключения к локальной сети по адресу устройства или его mDNS-имени. Внизу формы есть сброс настроек с подтверждением.

## Голосовой запрос

Устройство использует half-duplex цикл: `ГОТОВА → СЛУШАЮ → ДУМАЮ → ОТВЕЧАЮ → ГОТОВА`. Gateway сохраняет запись как задачу, обрабатывает её и возвращает WAV; каждому устройству нужен отдельный bearer-токен.

На содержательную диктовку Затея отвечает коротко, сохраняет исходную расшифровку и оформленную мысль в Obsidian, а затем коммитит и отправляет изменения в `origin`. Подробности — в [руководстве LLM Wiki](docs/voice-knowledge.md).

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `firmware/` | ESP-IDF/PlatformIO прошивка M5Stack StickS3 |
| `backend/` | FastAPI Gateway, LLM/STT/TTS-клиенты, архив, Obsidian writer и Git publisher |
| `deploy/` | подготовка данных и systemd unit |
| `docs/` | архитектура, протокол, разработка, прошивка и схемы |
| `docker-compose.yml` | запуск единственного backend-контейнера |
| `.env.example` | шаблон переменных без рабочих секретов |

`.env`, Wi-Fi пароли, device tokens, API-ключи и SSH-ключи не коммитьте. Setup AP открыт и предназначен для настройки в непосредственной близости от устройства.

### mDNS

Диктофон публикует имя `zateya-<MAC>.local`, например `zateya-7ce8b1e4b780.local`. Полный setup доступен через это имя в локальной сети или через `http://192.168.4.1/` в режиме точки доступа.
