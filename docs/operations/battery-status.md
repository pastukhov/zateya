# Батарея и USB в строке состояния

Слева — сервер и Wi-Fi; справа — значок USB, молния и процент батареи.
Зелёный USB означает наличие USB-питания, серый — отсутствие. Молния появляется
только при активной зарядке; полностью заряженное устройство с USB может
показывать зелёный USB без молнии. При ошибке измерения отображается `--%`.
Уровень не выше 15% выделяется красным.

Данные читаются раз в секунду из M5PM1: 0x04 bit0 — USB, 0x22/0x23 —
напряжение батареи (little-endian mV), 0x12 bit0 — CHG_STAT (активный ноль).
Для зарядки дополнительно требуется внешний источник питания.
Процент приблизительный: напряжение сглаживается (EMA 1/4), затем используется
оценка M5Unified `(mV - 3300) / 8`, ограниченная 0–100. Это не fuel gauge:
нагрузка, зарядка и состояние аккумулятора влияют на показания.

Источник: [официальный M5Unified Power_Class](https://github.com/m5stack/M5Unified/blob/master/src/utility/Power_Class.inl),
ветки getBatteryLevel и isCharging для board_M5StickS3;
[регистры M5PM1](https://github.com/m5stack/M5Unified/blob/master/src/utility/power/M5PM1_Class.inl).

Проверки: 96 native-тестов, включая граничные напряжения, различение зарядки
и внешнего питания, недостоверные данные и границы отрисовки; ESP32 build.

## Проверка на устройстве 17 октября 2026

Подписанный выпуск 17 установлен pull OTA через KeenDNS и подтверждён
локальной самопроверкой. Readiness после загрузки — 200. M5PM1 сообщает
4186–4190 mV, оценка 100%, USB=1. В журнале видны переходы CHG_STAT между
зарядкой и её отсутствием при неизменном подключении USB — это отдельный
аппаратный сигнал. Визуальное переключение при отключении кабеля проверяет
пользователь; оно не следует из одного только успешного OTA.
