# Экран диктофона в четырёх ориентациях

Пользователь согласовал 0/90/180/270 градусов и поручил реализацию.
Горизонтально: два столбца, основное состояние/таймер слева, связь/питание/режим
справа. Вертикально: состояние сверху, компактные показатели снизу.
Сохраняются русские тексты, ошибки, OTA, настройка с QR, режимы кнопки и wake word.
Длинные сообщения должны помещаться без обрезания, при необходимости занимая
всю доступную область. Поворот не должен прерывать запись или воспроизведение.

Выбран адаптивный layout для четырёх сторон. Только два горизонтальных положения
пользователь отклонил; простое вращение портретного изображения не использует
ширину горизонтального экрана и не реализует два столбца.

BMI270 содержит акселерометр/гироскоп, компас не нужен. Ориентацию определяем по
гравитации: устойчивое направление 500 мс, подавление дрожания около диагоналей,
при почти горизонтальном положении сохраняем последнюю сторону. При ошибке
датчика сохраняем экран и остальные функции; стартовая ориентация портретная.
Конкретные пороги и mapping осей проверяются тестами и затем на устройстве.

Проверка: host-тесты фильтра/геометрии, визуальные framebuffer-макеты всех сторон
и состояний, native suite, StickS3 build. Аппаратная приёмка на ASUS отдельно:
оси, плавность, лежащий экран, запись/звук, энергопотребление. До этой проверки
не утверждать, что автоповорот физически работает; не публиковать OTA вслепую
поверх незавершённой диагностики OTA29.
